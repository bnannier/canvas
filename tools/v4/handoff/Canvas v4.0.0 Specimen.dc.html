01
Light is the material

Surfaces are lit glass: a translucent fill, a 1px top highlight, depth from one soft ambient shadow. Nothing is flat and nothing is gradient-heavy.

02
One charged accent

A single ion hue does every job: fill, focus, selection, glow. It is one oklch token, so rebranding is one value and the palette stays in gamut. Try the dots in the nav.

03
Type carries hierarchy

Bricolage Grotesque for display and titles, Instrument Sans for UI, JetBrains Mono for anything a machine reads. Size and weight do the work, not color.

04
Motion is a spring

Every press, toggle and slide runs on one spring curve, .34 / 1.56 / .64 / 1. Entrances rise 16px. Nothing fades in place. Reduced motion zeroes all of it.
