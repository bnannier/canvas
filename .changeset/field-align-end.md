Field: new `alignEnd` boolean. Display-mode values rest at the leading edge by default (unchanged); passing `alignEnd` packs each row's value (text, badges, the copy row, an avatar stack) to the row's trailing edge, receipt / iOS-Settings style, with wrapped value text keeping its lines on that edge. Display mode only; the control-mode label / Input / message stack is unaffected.
