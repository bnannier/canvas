Two new options for a page header, the user-visible capability this minor adds. Breadcrumb
takes `subtle`, a quieter trail with the ancestors in the subtle ink and the current page at
the regular weight. Button takes `pageLink`, a 34 px hairline link around a muted label, and
`mono` to set that label in the 400 12 px mono face for a source path. The component detail
page's header now draws both, as the v4 hand-off does.
