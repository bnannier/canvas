A docs link or deep link can open the mint palette: `?palette=blush|mint` rides beside `?scheme` and `?surface`, the docs hand it to the kit's ThemeProvider as `mint` (dark still wins), and the phone web drawer's appearance footer gains a Blush/Mint control in the light scheme. The preview opener validates each of the three axes on its own, refuses a value outside its set by name, and now quotes the Android remote command for the device's shell: `adb shell` joins its words and the device's sh parses them again, so the `&` between two axes had sent `am start` to the background and the emulator opened every multi-axis link with only its first axis. The page shown when a launch fails prints a hand-run command that pastes into zsh or bash unchanged. The opener's pure half moves to `docs/scripts/preview-links.mjs`, pinned by `tools/docs/preview-server.test.ts`, which splits the commands back through real shells; an end-to-end test clicks the drawer's Palette control and reads the backdrop repaint, and the scheme and palette checks read the page backdrop itself rather than the largest opaque box. Repository tooling and docs only; nothing in the package changes.
