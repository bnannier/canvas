VoiceOver and TalkBack no longer read a field's visible label twice or speak its required star, and they now hear a required field as required. On iOS and Android the label of Input, Textarea, Select, Autocomplete, PhoneInput and Stepper (above the field, or floating in it on Android) is hidden beside the field it names, so the screen reader stops once, on the field. React Native has no native required state (its `aria-required` reaches the web alone), so a required field's own name says it there: "Full name, required" for Input, Textarea, Autocomplete, PhoneInput's number field and Stepper's group and field, as Select's trigger already said on every platform; a name the caller gives through `accessibilityLabel` takes the word too. Before, the only native cue was the star in the label's own stop, beside the field. The label Field draws over a control that names itself (a Switch) stays a stop of its own, named without its star and, when `required`, as "Notifications, required". Stepper's native group no longer carries an `aria-required` that React Native dropped. The web is unchanged: the label stays in the page as the field's `aria-labelledby` target, the star stays `aria-hidden`, and the field's `aria-required` announces it.
