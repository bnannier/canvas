Comments in the skins and the CSS hand-off no longer name the brand Canvas replaced, call the violet `primary` indigo, or call a skin "the established Canvas look", and every corner a comment states is one the code it sits on draws: a comment over an element states that element's corner, and a module's header comment names roles (the field corner, the iOS menu corner, a capsule) rather than numbers. The hand-off's MediaObject, GridList and Autocomplete notes said 10pt where the iOS skins draw 12 and 8. Source comments that stated a corner their element does not draw now state the one it does: the web Autocomplete and Select option rows (said 10, draw the control corner, 8), the iOS and Android DataTable outlines (said 10 and 8, draw the card corner, 12), the iOS ButtonGroup stepper (said rounded 8, draws capsule ends), the iOS RowMenu card (said about 28pt, draws the iOS menu corner, 26), the iOS StackedList overflow button (said the web's control corner, draws a circle), the iOS Feeds card (said the grouped-list corner, draws the iOS card corner), the iOS Card note (called its 12 corner larger than the web's 14), and the Select shell note (said no option row has a corner, where only the Android rows have none). A comment over several elements states a number only every one of them draws, so the web DataTable skin's "10px-cornered" header note now sits on the header band, and the iOS and Android GridList entry notes name the Card's corner role rather than a number over the whole build. DESIGN.md's Shapes section now says when a native skin may draw a part the web's way: only by sharing the web skin's same part (drawn from the same place), and only where the platform gives that part no shape, because the component's row in PLATFORM-REFERENCES.md says the platform ships no control for the job or the part is declared with the reason; and that a constant, helper or component no platform names, in any module, is drawn by every skin that uses it. These are comment and documentation changes only; nothing they describe renders differently.
