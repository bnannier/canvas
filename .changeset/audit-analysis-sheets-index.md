The component audit gains its analysis, contact sheets and reviewer index. `bun run audit:analyze` writes an `analysis.json` beside the newest capture of every cell: contrast from the DOM where the probe resolved it, and where it could not (every glass cell) the text's painted ink (its colour, its own alpha and its opacity, which the probe now records) over the background read from the photograph (labelled `painted-ink+pixel-background`; the 10th and 90th luminance percentiles, `pixel-percentiles`, only for a text with no painted ink colour), under 4.0 of 4.5 fail-likely and up to 4.5 to review; the smallest painted size against the type floors, small targets per platform, the web row's accessibility tree held identical across looks and surfaces at one width, on devices the names of the controls a screen reader announces, and a cell recorded as failed filed under `failed` whatever it left on disk. `bun run audit:calibrate` measures the photograph readings against the DOM. `bun run audit:sheets` lays every variant's cells out on JPEG contact sheets no longer than 1600 px on either edge, each tile labelled with its cell id and the commit it was captured at, each sheet titled with the runs it draws from, and a grid too large to read at 0.6 px a CSS px cut into numbered sheets: the browser card by widths and looks, each platform row by looks and surfaces, the device cards, and the browser's iOS and Android rows beside the devices' own. `bun run audit:index` builds `.audit/current/` from the newest capture of each cell across every run, so a partial re-capture replaces only the cells it took, with an index per component (checklist, sheets, and every cell's flags, run, commit and fingerprint) and a summary ranked by flags; `bun run audit:prune` deletes old runs while keeping the newest two captures of every cell, then rebuilds the index over what remains so none of its links points at a deleted run. The native host now stamps each cell with the time it finished. Repository tooling and docs only; nothing in the package changes.
