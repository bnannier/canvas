The component audit gains its analysis, contact sheets and reviewer index. `bun run audit:analyze` writes an `analysis.json` beside the newest capture of every cell: contrast from the DOM where the probe resolved it, and where it could not (every glass cell) sampled from the photograph at the text's ink (10th and 90th luminance percentiles, labelled `pixels`, under 4.0 of 4.5 fail-likely and up to 4.5 to review), the smallest painted size against the type floors, small targets per platform, the web row's accessibility tree held identical across looks and surfaces at one width, and on devices the names of the controls a screen reader announces. `bun run audit:sheets` lays every variant's cells out on JPEG contact sheets no longer than 1600 px on their long edge, each tile labelled with its cell id: the browser card by widths and looks, each platform row by looks and surfaces, the device cards, and the browser's iOS and Android rows beside the devices' own. `bun run audit:index` builds `.audit/current/` from the newest capture of each cell across every run, so a partial re-capture replaces only the cells it took, with an index per component (checklist, sheets, and every cell's flags, run, commit and fingerprint) and a summary ranked by flags; `bun run audit:prune` deletes old runs while keeping the newest two captures of every cell. The native host now stamps each cell with the time it finished. Repository tooling and docs only; nothing in the package changes.
