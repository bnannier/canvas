Checkbox gains a `description` prop, matching Radio and Switch: pass the label as children and the secondary line as `description`, and the control stacks the title over its muted description for you, box aligned to the first text line and the whole row tappable. Long labels now wrap within the row instead of forcing it wider, and the box's first-line nudge applies only when text sits beside it.
