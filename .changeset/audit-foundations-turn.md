The component audit gains its Foundations tier and a one-command turn capture. Each of the 15 foundations (the style-layer renderables with no component page, AnchoredOverlay through ThemeProvider, and the design tokens the `tokens/*` pages document) has a checklist under `audit/foundation/`, generated and checked by `audit:checklists` and counted by `audit:status`: its source files, its public exports with their API manifest kind and K12-2 status, the docs routes that document it or are planned to, the tests that import it, and its consumers, every kit component that renders through it, read from the source by a new reader (`tools/audit/kit-graph.ts`) directly, through shared modules or through other kit components, with the Capture through list its turn re-captures. `bun run audit:turn -- --slug=<slug> --phase=before|after` takes a component's, page's or foundation's capture in one command: the web export reused when it is this checkout's and built when it is not, served on the turn's own port, the variants, states and pages on the web, the installed Canvas Audit build on iOS and Android reused when it is this checkout's Release build and rebuilt incrementally when it is not, the native capture, then the analysis, sheets and index scoped to the slugs, with every run id recorded under its phase in `audit/turns/<id>.md`, which every checklist now links; `--dry-run`, `--web-only`, `--native-only` and `--only-first=<n>` for a large foundation. Repository tooling and docs only; nothing in the package changes.
