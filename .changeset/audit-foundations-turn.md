The component audit gains its Foundations tier and a one-command turn capture. Each of the 16 foundations (the style-layer renderables with no component page, AnchoredOverlay through ThemeProvider; the design tokens the `tokens/*` pages document, with the names those pages show and every other public name of their modules; and FoundationReference, the kit internals the generated `/foundation` page documents) has a checklist under `audit/foundation/`, generated and checked by `audit:checklists` and counted by `audit:status`: its source files (its implementation included: the private declarations its exports read), its seams (the private declarations it alone reads), its public exports with their API manifest kind and K12-2 status, the docs routes that document it or are planned to, the tests of it, and its consumers, every kit component that renders through it, read from the source by a new reader (`tools/audit/kit-graph.ts`) directly, through shared modules or through other kit components, with the Capture through list its turn re-captures. Every deprecation the owner decided is on one of those checklists, and `audit:checklists:check` fails on one that is not. `bun run audit:turn -- --slug=<slug> --phase=before|after` takes a component's, page's or foundation's capture in one command: the web export reused when it is this checkout's and built when it is not, served on the turn's own port, the variants, states and pages on the web, the installed Canvas Audit build on iOS and Android reused when it is this checkout's Release build and rebuilt incrementally when it is not, the native capture, then the analysis, sheets and index scoped to the slugs, with every run id recorded under its phase in `audit/turns/<id>.md`, which every checklist now links; `--dry-run`, `--web-only`, `--native-only` and `--only-first=<n>` for a large foundation. Every audit command reads a name the same way, a component's slug naming the component alone (`calendar`, whose template page is `template-calendar`); a web run that cannot tell whose source it captures is refused with exit 2, and the turn stops on a refused run whatever its exit status; and a run is recorded dirty only when the source it captured differs from its commit. Repository tooling and docs only; nothing in the package changes.
