# Canvas docs. Everything here is public documentation, so crawl all of it.
#
# This file has to exist as a real file. docs/public/_redirects rewrites every
# unmatched path to index.html with a 200, so without it /robots.txt answers with
# the HTML shell, and a crawler parses that markup as directives: Lighthouse read
# it as 74 malformed rules. A missing file is silent here in a way it is not on a
# host that would simply 404.
#
# No Sitemap line on purpose: there is no sitemap.xml to point at, and naming one
# would recreate the same problem, since the catch-all would answer that URL with
# HTML too. Add the directive in the same commit that starts generating the file.
User-agent: *
Allow: /
