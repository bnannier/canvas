Name: **Canvas UI**

Subtitle: **Build universal app UI**

Publisher: **Bobby Nannier** (owner-approved display name).

Category: **Developer Tools** (confirm the portal's available category).

Build or fix application screens with `@nannier/canvas`, the universal React Native
UI kit for web, iOS, and Android. Canvas UI helps your agent resolve the installed
package API, compose semantic controls and responsive layouts, and check state,
accessibility and rendered behavior on available runtimes.

Use it in an application workspace with development tools. Native runtime checks
need an available simulator or device. The plugin contains one skill; install
Canvas and the app's required dependencies separately. It does not replace a
different chosen UI library, edit Canvas's private source, or publish your app.
There are no MCP servers, hooks, telemetry or account connections in this package.

Starter prompts:

- Build a settings screen with Canvas for web, iOS, and Android.
- Fix the Canvas dialog in this app and verify keyboard focus.
- Check this Canvas layout at desktop and phone widths.
